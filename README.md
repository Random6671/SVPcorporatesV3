# SVP Corporates — MIHAN

Standalone single-page website for SVP Corporates at Anjani Exotica, MIHAN, Khapri, Nagpur.

## Current direction
- Cinematic full-bleed hero with transparent → warm-ivory navigation transition
- Cormorant Garamond + DM Sans typography
- Owner-provided corporate accommodation copy and structure
- Actual property photography supplied by the owner/user throughout the site
- Responsive desktop/tablet/mobile layouts
- Scroll reveal and active navigation interactions

## Files
- `index.html` — complete website
- `assets/` — local property photographs used by the site

Open `index.html` directly in a browser. The property photography is fully local; only the Google-hosted webfonts require an internet connection.
